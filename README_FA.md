# همراه تمرین — نسخه ۲

وب‌اپ فارسی مدیریت تمرین مقاومتی، برنامه ۱۲ هفته‌ای و پایش علائم. برای اجرا روی GitHub Pages، فایل‌های این پوشه را **مستقیماً در ریشه مخزن** قرار دهید؛ `index.html` باید در ریشه باشد.

## قابلیت‌های نسخه ۲

- رابط کاربری تازه، مینیمال و واکنش‌گرا برای موبایل و دسکتاپ.
- بخش **حرکات**: برای هر حرکت یکی از سه وضعیت «مجاز در برنامه من»، «نیازمند بررسی» و «ممنوع در برنامه من» انتخاب کنید. این برچسب‌ها مدیریت شخصی برنامه‌اند و تأیید پزشکی نیستند.
- یادداشت اختصاصی هر حرکت برای ثبت نظر پزشک، محدودیت‌ها یا تجربه علائم.
- بخش **برنامه**: حرکت‌های جلسات A و B را در هر فاز چهار‌هفته‌ای با حرکت دیگری جایگزین کنید یا آن‌ها را حذف کنید.
- بخش **حرکات ← افزودن حرکت جدید**: نام فارسی و انگلیسی، توضیحات اجرا، عضلات هدف، تجهیزات و لینک ویدیوی آموزشی را وارد کنید.
- حرکات «ممنوع» و «نیازمند بررسی» اجازه علامت‌زدن ست جدید را نمی‌دهند. در صورت تبدیل یک حرکت به این وضعیت‌ها، ست‌های انجام‌شده در پیش‌نویس‌های باز دیگر انجام‌شده محسوب نمی‌شوند. **سوابق ذخیره‌شده قبلی حذف نمی‌شوند.**
- پایش درد، گزگز دست راست و چپ، بیدارشدن از خواب، تغییرات عصبی، پیشرفت ست‌ها و وزن.
- گزارش‌ها، CSV و پشتیبان کامل JSON شامل حرکت‌های سفارشی و وضعیت‌ها.

## به‌روزرسانی از نسخه ۱

۱. در اپ فعلی به **تنظیمات ← پشتیبان JSON** بروید و نسخه پشتیبان را در محل امن ذخیره کنید.
۲. فایل‌های نسخه ۲ را در ریشه مخزن GitHub قبلی بارگذاری و فایل‌های هم‌نام را جایگزین کنید. نام مخزن، آدرس سایت و محل نصب نباید تغییر کند.
۳. پس از موفق‌شدن GitHub Pages، اپ را باز و یک بار بارگذاری مجدد کنید؛ ممکن است بارگذاری مجدد دوم برای فعال‌شدن service worker جدید لازم باشد.
۴. در همان مرورگر/اپ قبلی و روی همان گوشی، اطلاعات نسخه ۱ باید باقی بمانند، چون کلید localStorage و نسخه طرح داده تغییر نکرده است. بااین‌حال حتماً پشتیبان مرحله ۱ را نگه دارید.
۵. اگر داده‌ها در همان مرورگر موجود نبودند، از «تنظیمات ← بازیابی پشتیبان» استفاده کنید.

**توجه:** داده‌ها بین دو مرورگر، حالت Private و دستگاه‌های مختلف به‌صورت خودکار منتقل نمی‌شوند. فایل پشتیبان شامل اطلاعات سلامت است و نباید در GitHub عمومی منتشر شود.

## نصب روی گوشی

- آیفون: Safari ← Share ← Add to Home Screen.
- اندروید: Chrome ← Install app / Add to Home screen.
- لینک‌های بیرونی ویدیویی به اینترنت نیاز دارند؛ صفحات برنامه با service worker برای استفاده آفلاین نگهداری می‌شوند.

## ملاحظات پزشکی

- برنامه فقط ابزار نظم‌دهی و پایش است؛ مجوز پزشکی صادر نمی‌کند.
- طبیعی‌بودن نتیجه قدیمی نوار عصب و عضله، به‌تنهایی علائم فعلی، تماس دیسک‌ها با نخاع یا محدودیت‌های وزنه‌زدن را رد نمی‌کند.
- محدودیت پزشک درباره حرکت‌های وزنه‌دار بالای سر پابرجاست.
- در صورت گزگز جدید/بدترشونده، ضعف جدید، اختلال مهارت دست‌ها یا تعادل، تمرین را متوقف کرده و ارزیابی پزشکی مناسب بگیرید؛ علائم عصبی ناگهانی یا شدید نیازمند ارزیابی فوری‌اند.
- سطح حرکات در ویدیو ممکن است از نسخه ساده موجود در برنامه سخت‌تر باشد؛ ویدیو تأیید فردی برای اجرا نیست.
