# همراه تمرین — دفترچه ورزشی شخصی (نسخه آزمایشی ۱)

یک وب‌اپ فارسی، راست‌به‌چپ و بدون حساب کاربری برای ثبت برنامه ۱۲ هفته‌ای و پایش علائم. **این ابزار جایگزین ارزیابی عصبی حضوری و تأیید متخصص پیش از شروع تمرین مقاومتی نیست.**

## استفاده فوری روی لپ‌تاپ

فایل جداگانه `hamrah-tamrin-offline.html` را دانلود و با Chrome، Firefox یا Edge باز کنید. صفحه بدون اینترنت باز می‌شود، اما لینک ویدئوها برای پخش به اینترنت نیاز دارند. در نسخه فایل محلی، مخصوصاً در Safari/iOS، تداوم ذخیره‌سازی ممکن است تضمین‌شده نباشد. همیشه از تنظیمات اپ، پشتیبان JSON بگیرید.

## نصب مثل اپ روی گوشی (PWA)

۱. فایل ZIP را باز کنید و **محتویات پوشه** `neck-strength-app` شامل `index.html`، `manifest.webmanifest`، `sw.js` و فایل‌های آیکن را به یک سرویس میزبانی استاتیک دارای **HTTPS** منتقل کنید. برای مثال GitHub Pages یا Cloudflare Pages. گزینه دیگر انتشار پوشه در Netlify Drop است.

۲. لینک HTTPS سایت را روی گوشی باز کنید.

۳. در آیفون: Safari > Share > Add to Home Screen. در اندروید: Chrome > منو > Install app یا Add to Home screen.

۴. پس از نصب، خود وب‌اپ و داده‌های ثبت‌شده روی همان گوشی ذخیره می‌شوند. بازشدن ویدئوهای بیرونی همچنان اینترنت می‌خواهد.

**نکته حریم خصوصی:** اگر وب‌اپ را با GitHub Pages منتشر کنید، صفحات و کد منتشرشده قابل مشاهده‌اند. متن ثابت برنامه شامل محدودیت‌های عمومی و برخی علائم مورد پایش است، اما داده‌هایی که بعداً در مرورگر وارد می‌کنید به سرور ارسال نمی‌شوند. برای اطلاعات حساس از پشتیبان رمزگذاری‌شده و محل ذخیره امن استفاده کنید. فایل JSON خروجی حاوی داده‌های سلامت است؛ آن را عمومی نکنید.

## قابلیت‌ها

- جلسه A، جلسه B، هوازی اختیاری، و ثبت روزانه علائم بدون ورزش
- ۱۲ هفته در ۳ فاز ۴ هفته‌ای، با ست و تکرار پیشنهادی
- ثبت انجام ست، تعداد تکرار واقعی و وزنه استفاده‌شده
- ویدئوهای آموزشی از مراکز فیزیوتراپی/مرکز پزشکی، با پیوند به صفحه اصلی ویدئو
- درد قبل و بعد، گزگز راست/چپ قبل و بعد، تعداد بیداری شبانه، RPE، یادداشت آزاد
- توقف علامت‌گذاری ست جدید در صورت ثبت تشدید گزگز/بی‌حسی یا علائم هشدار عصبی
- تاریخچه ۲۸ روز اخیر و تمام جلسات، نمودار درد و گزگز، تعداد جلسات هفتگی
- ذخیره محلی، تهیه پشتیبان و بازیابی JSON، خروجی CSV

## ایمنی

به دلیل MRI گردن و گزگز دوطرفه شبانه، افزایش بار تمرین باید پس از ارزیابی عصبی و با نظر متخصص باشد. ممنوعیت اعلام‌شده پزشک درباره حرکت‌های دارای وزنه بالای سر در برنامه رعایت شده است. هشدارهای داخل اپ غربالگری و یادآوری هستند، نه تشخیص یا مجوز پزشکی. علائم عصبی جدید یا بدترشونده را جدی بگیرید.

## محدودیت‌ها

- **همگام‌سازی بین دستگاه‌ها ندارد.** برای انتقال از گوشی به لپ‌تاپ فایل JSON خروجی بگیرید و در دستگاه دیگر بازیابی کنید.
- هیچ سرور، حساب کاربری یا رمز عبور ندارد و داده‌های مرورگر ممکن است در پاک‌سازی حافظه از بین بروند.
- ذخیره در حالت ناشناس مرورگر پایدار نیست.
- حرکات و نسخه‌های نشان‌داده‌شده در ویدئو ممکن است شامل سطح‌های دشوارتر از نسخه برنامه باشند؛ فقط نسخه ساده توضیح‌داده‌شده را اجرا کنید.
- دانلود ZIP به‌تنهایی به معنی نصب PWA نیست؛ برای Install نیاز به میزبانی HTTPS دارد.

ساخته‌شده به‌عنوان نسخه آزمایشی متناسب با برنامه مطرح‌شده در گفتگو. نیازمند تطبیق با نظر پزشک/فیزیوتراپیست و وضعیت علائم واقعی است.
